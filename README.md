# Thumbnail Lab — サムネ工房

過去のサムネイルをお手本として整理し、ChatGPTで作った5案を比較して、選んだ理由を次回の依頼文に引き継ぐローカルWebアプリです。

**試作版です。アプリ自身による画像生成・画像解析・モデルの追加学習は実装していません。** お手本画像と依頼文をChatGPTへ渡し、生成結果を手動で登録する方式です。ChatGPTやOpenAIの公式アプリではありません。

## できること

- チャンネル別のお手本画像の登録（1チャンネル30枚まで）
- 今回のお手本を最大5枚選択
- 題材・表示文字・作風ルール・採用履歴から、5案分の依頼文を作成
- 生成済み画像を5案の比較欄に登録し、採用案と理由を保存
- 採用理由を次回の依頼文に反映／反映を停止
- SQLiteでデータを保持し、JSONバックアップを書き出し

ここでいう「学習」は、採用理由を次の指示に含める仕組みです。画像を自動分析して好みを推定したり、AIモデルの重みを更新したりするものではありません。未採用案を自動で嫌いと判断しません。

## 起動

Python 3.9以降と、最近のChrome・Safari・Edgeなどを使用してください。Pythonの外部パッケージやAPIキーは不要です。

```sh
git clone https://github.com/matsumoto-akio/thumbnail-lab.git
cd thumbnail-lab
python3 server.py
```

ブラウザで [http://127.0.0.1:8769](http://127.0.0.1:8769) を開きます。Windowsで`python3`がない場合は`python server.py`を使用してください。停止するには起動したターミナルでCtrl+Cを押します。

## 使い方

1. チャンネルを登録します。仮の名前でも始められます。
2. 過去サムネを追加し、参考にする画像に★を付けます。
3. 作風ルール、今回の題材、サムネに入れる文字を入力します。
4. 「5案の依頼文を作る」を押します。
5. 依頼文をコピーし、お手本画像と一緒にChatGPTへ渡して画像を生成します。
6. 生成した画像を案1〜5へ登録します。
7. 好きな案を選び、理由を記入して保存します。反映を有効にした理由は、次に作る依頼文へ含まれます。

例：「文字が読みやすい」「顔の大きさがちょうどよい」。一度だけの要望は反映をオフにしてください。

ChatGPT側の画像生成の利用条件や上限は、利用中のサービスに従います。このアプリから生成APIへのリクエストは送りません。

## データと保存先

画像・採用履歴は、起動した端末の`library.sqlite3`に保存します。初回は空の状態で始まります。外部サーバーへの画像送信、アクセス解析、外部フォント読み込みはありません。ChatGPTへの添付は利用者が行います。

- 画像形式：PNG / JPEG / WebP、1枚4MBまで
- 保存リクエスト全体の上限：80MB（画像の文字列化に伴う増分を含む）
- 次回の依頼文に反映する採用理由：有効な直近20件まで
- チャンネル全体を毎回保存する簡易構成のため、大量画像の管理には向きません
- 「データを書き出す」でJSONを保存できます。JSONの取り込み画面は未実装です
- 完全なバックアップには、サーバーを停止して`library.sqlite3`を別の場所にコピーしてください

環境変数`THUMBNAIL_LAB_PORT`でポート、`THUMBNAIL_LAB_DB`でSQLiteファイルの保存先を変更できます。DBの親フォルダは事前に作成してください。

本アプリは`127.0.0.1`だけで待ち受ける、個人向けのローカルツールです。ログイン機能はありません。インターネットへの公開や複数ユーザーでの利用を想定していません。GitHub PagesではPythonサーバーが動かないため、そのまま利用できません。

## テスト

テスト時のみNode.js 18以降も必要です。

```sh
python3 -m py_compile server.py
python3 test_server.py
node --check public/app.js
node test_prompt.cjs
```

サーバーテストでは一時DBを使用し、通常の登録データは変更しません。テストポート18769が空いている必要があります。
