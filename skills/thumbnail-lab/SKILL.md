# サムネ工房

ユーザーが題材を伝えたら、お手本の読み込み、5枚の生成、比較画面への登録まで担当する。プロンプトのコピーや画像の手動登録をユーザーに頼まない。チャンネル・お手本・題材が不明なら既存の会話とライブラリを確認し、不足する情報だけ聞く。

## 実行環境

画像生成ツール、ローカルファイル操作、起動中のサムネ工房サーバーが必要。標準URLは `http://127.0.0.1:8769`。サーバーが別マシンならその環境の指示に従いヘルパーをサーバー側で実行する。生成環境と保存先が異なる場合は参照・生成ファイルを転送し、それぞれ実在するパスを使う。ツールがないときに成功を装わず、欠けている機能を説明する。有料APIへ独断で切り替えない。

ヘルパーはこのSKILL.mdと同じフォルダの `scripts/library.py`。以下のパスを実際のインストール先に解決する。

## 制作

1. 対象チャンネルのAGENTS.md、仕様書、専用スキル、feedback、最新承認例と、環境の制作・保存ルールを先に読む。本スキルは作風の代わりにならない。資料がないまま独自の作風で進めない。
2. `python3 scripts/library.py list` でチャンネルを確認する。重複名はIDで指定する。
3. `python3 scripts/library.py context --channel CHANNEL_ID --out WORK_DIR/references` でお手本と有効な採用理由を取り出す。WORK_DIRはチャンネルの保存ルールに従う非公開の作業先。公開リポジトリ内へ画像を保存しない。
4. お手本を画像閲覧ツールで実際に見て、字体・太さ・縁、配色、顔と文字の比率、余白、装飾を確認する。最新の明示指示と承認例を優先し、過去の題材を誤って流用しない。
5. 利用可能な画像生成ツールを使い、お手本を参照画像として渡す。正確な文字と比率を維持し、独立した5枚を作る。コラージュにはしない。案1は最も忠実、案2は主役の大きさ、案3は文字配置、案4は表情・視線、案5は題材の見せ場を変える。チャンネル仕様に反する変更はしない。環境の画像生成スキルとツール手順に従い、5枚が揃ったら止める。生成量・費用の許可範囲を超えて再生成しない。
6. 生成結果を実際に見て誤字・見切れ・仕様違反を確認する。5枚の保存先を確認して一括登録する。失敗した場合は完成した画像を保持して未完了の案を明示する。偽のプレビューで成功扱いにしない。

```sh
python3 scripts/library.py import --channel CHANNEL_ID --batch-id UNIQUE_RUN_ID --topic "今回の題材" --headline "表示文字" --images /absolute/1.png /absolute/2.png /absolute/3.png /absolute/4.png /absolute/5.png
```

同じ制作の再試行には同じbatch-idを使う。重複エラーなら既存登録を確認し、別IDで二重登録しない。競合409なら最新状態と対象チャンネルの変更を確認してから再試行する。1枚4MB以内のPNG/JPEG/WebPを使用する。

7. 比較画面 `/#compare` で5枚の表示を確認し「5案できました。好きな案を選んでください」と案内する。画面は変更を定期取得する。手動入力中は更新を待つため、必要なら入力を保存して再読み込みする。

## 選択と次回への反映

選択はユーザーが決める。理由入力は任意で、選ぶだけでも保存できる。理由があれば次回参照し、なければ選択履歴だけ保持する。未採用案を嫌いと推測したり、採用理由を捏造したりしない。「学習」は履歴参照でありモデルの追加学習ではない。
